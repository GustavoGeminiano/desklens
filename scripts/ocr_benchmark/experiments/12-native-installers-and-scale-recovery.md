## Scale experiment and negative trials

Frozen local V2 reproduced the mandatory screenshot at 100%, 150%, 200%, but
failed at 125% (`if 1 % 2 = 0:`). Pixel-only line trials are reproducible with
`diagnose_variants.py --input IMAGE --rect 0 55 676 58 --output REPORT` on the
125% image generated by `smoke_packaged.py`. `12-pixel-variants.json` records all
outputs, including unsuccessful upscale, downscale, grayscale, inversion and CLAHE.
Only Otsu binarization recovered the complete literal line in this trial.

The worker now permits two pixel variants (150% cubic and Otsu) for at most three
whole lines with confidence below 0.90, using the same model. It selects a different
glyph output only with >0.02 confidence improvement within that same model and
keeps uncertainty/evidence. No regex, dictionary or Python parser inserts symbols.
An initial policy also replaced agreeing reads and regressed code_04 indentation:
development CER rose from 0.8730% to 1.5079%. Agreeing glyph sequences now retain
the original aligned geometry; whitespace-only differences cannot replace it.

Local actual inference recovered all four screenshot scales with the bounded
reread. A frozen test before the agreeing-geometry adjustment also passed all four
scales, startup 1431.40 ms and warm median 2052.96 ms under concurrent compilation.
The final revised worker requires a fresh packaged/native CI validation; these
local figures are not final cross-platform latency results.

Windows pipes explicitly use UTF-8, with a subprocess regression forcing legacy
cp1252 encoding and an accented input path plus emoji output. Packaged smoke now
uses an accented directory and asserts 100/125/150/200% literal fidelity. The test
driver needs Python; the installed application's child PATH does not contain it.

Final local development rerun after retaining agreeing geometry: literal CER
0.8730%, text+box recall 93.6585%, 14/20 exact documents, identical to the prior
geometry pipeline. The 18 worker tests passed. No held-out result was used to
select the bounded pixel policy; final native held-out validation is pending.
